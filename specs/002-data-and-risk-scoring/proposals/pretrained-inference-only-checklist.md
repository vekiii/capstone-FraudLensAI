# Proposed Phase 5 inference-only replacement checklist

**Status: proposal; implementation gate closed.** Drafted 2026-11-13 for review on `model-implementations`. This checklist describes an inference-only path for an already-trained IBM HI-Small laundering model. It does not amend the approved specification, benchmark protocol or T029–T036, and none of its items is complete. See the [scope evidence](../../../evidence/tasks/feature-002-inference-only-scope.md) and [candidate audit](../../../evidence/tasks/feature-002-replacement-model.md). No currently audited candidate has passed the input-compatibility gate.

The team direction to investigate pretrained inference was reported by the user on 2026-11-13 in the [IBM model decision](pretrained-ibm-model-decision.md). Reviewer names, a formal decision on this checklist, accepted deviations from the original training tasks, an approved candidate, and an independent evaluation protocol are **not recorded**. The reported direction is not a waiver. Before implementation, reviewers must decide whether to adopt this scope, identify the responsible reviewer(s) and date, specify accepted deviations and affected requirements, and revise the spec, plan, research, evaluation/artifact contracts and task status coherently. Keep T029–T036 open until formally completed or superseded.

## Proposed tasks, in dependency order

- [ ] **P5I-01 — Candidate compatibility and exposure gate.** Verify an immutable pretrained IBM `Is Laundering` artifact and permitted use; exact downloadable weights, hash, format, runtime, full feature order/dtypes, fitted preprocessing state, bank-qualified account semantics, point-in-time historical cutoff and source-row population. Compare every required input with the approved IBM mapping and `history-v1` catalog. Reject a candidate with missing state, future/same-timestamp exposure, fabricated features, unsafe mandatory deserialization or unknown mandatory semantics. Record a field-level matrix and explicit outcome. **Maps to T029, T031, T032, T034.** Kluey, Daemons-Q and FraudSentinel are currently blocked; this task is open.
- [ ] **P5I-02 — Freeze a versioned inference manifest and evaluation policy.** After P5I-01 and actual scope approval, pin URLs/revisions/byte hashes, model and preprocessing identities, schema, dataset/feature policy, allowed runtime and failure outcomes. Define the operational score as raw versus calibrated accurately, a prospective threshold or explicit no-threshold policy, and label/holdout roles. Establish whether an independent population exists before permitting performance claims; prohibit publisher test-derived thresholds, holdout tuning and holdout reuse as confirmatory evidence. Hash and commit the approved version before model execution. **Maps to T029, T032, T033–T034, T035–T036.** This is a proposed alternative protocol, not the untracked original T029 draft.
- [ ] **P5I-03 — RED/GREEN artifact boundary.** First test absent, corrupt, substituted, wrong-domain, wrong-schema and wrong-runtime artifacts; approved local-root containment; no network or training; Foundation/rules independence. Then implement only approved native non-executable loading with pre-load hash/manifest checks. Any pickle/joblib conversion requires its own reviewed isolated process and validated primitive output; never deserialize it in the application. Record exact commands, results and trust limits. **Maps to T030–T031 and T035–T036 as an alternative loader path; it does not satisfy their fitting/selection requirements.**
- [ ] **P5I-04 — RED/GREEN IBM inference boundary.** Test and implement exact ordered feature construction for eligible IBM transactions, bank-qualified identity, data/version/feature-state lineage, strict scoring-time cutoff, categorical/missingness semantics, private-label exclusion, one-to-one transaction reference, bounded finite raw score and model provenance. Fail closed on any unavailable input; call predict only and prove no fitting or learned-parameter mutation. Preserve Foundation/rules scorers and existing API/UI. **Maps to T030–T032 and T035–T036 as an alternative scoring path; no candidate selection is implied.**
- [ ] **P5I-05 — Small real inference smoke and regressions.** Use a documented, label-free set of eligible local IBM events after artifact and feature checks; verify vector identity/order, repeatability, transaction identity, controlled rejection, unchanged weight bytes and Foundation/rules operation. Record exact sample counts, predictions, resource use, commands and exit codes. Distinguish a successful prediction from model quality evidence. **Maps to T034–T036 operational checks only; it cannot close metric/holdout tasks.**
- [ ] **P5I-06 — Independent evaluation decision and handoff.** Compare publisher training/validation/test row IDs or defensible source lineage against the local split; document any overlap and publisher threshold procedure. If a genuinely independent eligible labeled population and an approved frozen protocol exist, separately implement/test same-population rules comparison, metrics, frozen predictions before label join and one-time holdout disclosure. Otherwise report performance **unavailable**, leave sealed holdout untouched and avoid PR-AUC/ROC-AUC/precision/recall/F1 claims. Reconcile original tasks and obtain actual human review before any later publication/API work. **Maps to T029 and T032–T036; it does not silently satisfy them.**
