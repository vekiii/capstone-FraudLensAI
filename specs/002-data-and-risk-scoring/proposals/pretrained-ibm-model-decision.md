## Open technical decisions

| Question | Finding and required decision |
| --- | --- |
| Identity | Upstream groups and looks up `Account` / `Account.1` without `From Bank` / `To Bank`, and defines `self_loop` by unqualified account equality. FraudLens joins on bank-qualified account identities. Decide whether to retain the upstream semantics in an isolated adapter with explicit collision/meaning limits, or reject the artifact. Re-keying to bank-qualified accounts changes model inputs and must not be presented as equivalent. |
| History | Upstream computes graph tables from the full first 80% of rows, then applies the same tables to all training rows, its validation tail and test rows. This can include later transactions relative to an earlier row; it is not FraudLens `history-v1` strict prior-event 24-hour replay. Decide whether a separate versioned feature policy with these limitations is acceptable. Zero for missing account lookup is in upstream code, but is not permission to fill unavailable state or claim full coverage. |
| Preprocessing trust | The 33.1 MB `aml_lgbm_preproc.joblib` contains the graph dictionaries and feature/category order; the native text model alone is insufficient. `joblib.load` can execute code. Require a reviewed, non-executable extraction/verification path or reject the candidate; no deserialization until a separate security decision. Pin hashes, versions and supported Python 3.14/LightGBM runtime before loader tests. |
| Threshold and evaluation | The author computes PR curves and the 80%-recall routing threshold using **test labels**. That threshold is not independently validated and cannot satisfy FraudLens validation-only selection. The author's dataset name and 5,078,345-row count match our source, so prior training/test exposure of our rows is likely; exact byte/row identity remains unproven. Do not use our original holdout as a fresh independent benchmark without exposure proof and a newly approved evaluation design. |
| License | The model card declares Apache-2.0; the repository tree shows no separate LICENSE file. The source dataset has separate terms. Review the grant, attribution and dataset/derived-state redistribution obligations before acquisition or reuse. |
