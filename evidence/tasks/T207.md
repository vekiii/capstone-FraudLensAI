## Scope

Added `backend/tests/unit/test_dataset_resume.py` with synthetic rows and temporary directories. The four cases specify that an interrupted run retains a completed checkpoint without publishing a partial snapshot; resume rejects a corrupted staged chunk; disk exhaustion fails before consuming input or publishing output; and a successful resume reconciles counts, preserves source/config identity, publishes completion state and returns each source row once.

The tests establish a focused T208 interface: `fraudlens.data.pipeline.run_pipeline(rows, *, staging_dir, output_dir, source_sha256, config_hash, chunk_size, min_free_bytes, resume)`, `CheckpointMismatchError` and `DiskSpaceError`. The completed snapshot is represented by `manifest.json` and a `COMPLETE` marker under the output directory. Synthetic interruption is modeled by an iterator that raises `KeyboardInterrupt` after yielding a full chunk. This is a proposed implementation contract for T208; no pipeline implementation was added in T207.
