## Implementation

Added `backend/src/fraudlens/data/source.py` and its package initializer. `sha256_file` hashes raw bytes in bounded chunks. `iter_source_rows` computes this hash before opening the CSV parser, validates the complete exact header including duplicate `Account` entries, and streams records using `csv.reader` (not `DictReader`). It rejects an absent/changed header, malformed CSV/UTF-8, and any row whose width differs from the verified schema. Parsed source values remain strings; timestamps are not normalized and identifiers/amounts are not coerced.

The positional map is zero-based: timestamp 0, sender bank/account 1/2, receiver bank/account 3/4, remaining source columns 5–10. Stable IDs use the full lowercase SHA-256 plus the 1-based data row number: `ibm-hi-small:{sha256}:row:{n}`. The ID has no label or timestamp component. Original source bytes are read-only and never rewritten by these functions.

The T202 changed-header fixture was corrected during GREEN: its previous `renamed-field` case had accidentally retained the expected `Amount Received` value. It now genuinely changes the header and remains a rejecting case.
