Starting branch/HEAD: `model-implementations` / `8ac9bccdd08a8d5a2018b3e9413e75e9e72e8138`. Existing unrelated untracked T029 drafts were preserved. Original T029–T036 status is unchanged.

## FraudLens comparison contract

The approved [IBM mapping](../../data/mappings/ibm_hi_small_v1.json) binds the 11 ordered raw columns, including duplicate `Account` headers, to separate bank-qualified sender/receiver identities; it preserves both amount/currency sides and isolates `Is Laundering` as a private evaluation label. The [data model](../../specs/002-data-and-risk-scoring/data-model.md#history-v1-feature-catalog) defines eight prior-24-hour count/sum/distinct-counterparty features plus current paid amount, paid currency and optional actual payment format. A history snapshot uses strictly earlier events `[t-24h,t)` and excludes all same-timestamp peers. It has no entity file, lifetime graph, PageRank, cycle motifs, 72-hour windows or fitted publisher training aggregates. The local `data/raw/HI-Small_accounts.csv` was absent when checked; the selected transaction CSV was present. Neither candidate's published scores establish performance on this project's data or frozen protocol.
