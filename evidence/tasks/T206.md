## Implementation

Added `backend/src/fraudlens/data/validation.py`. `validate_rows` consumes a finite bounded batch and creates a deterministic report whose source count reconciles to accepted plus rejected counts. Accepted rows retain original field text, including amount precision and source timestamp spelling. Sender/receiver bank-qualified keys are represented as exact-text tuples. Monetary values are checked with `Decimal`; values are not converted to float, quantized, or assigned an unverified precision policy. Timestamp text is calendar-validated against the observed `YYYY/MM/DD HH:MM` syntax and retained unchanged; no timezone interpretation is introduced.

Each rejected row has one first-match reason from a fixed order and an allowlisted reason code. Ledger entries contain only `source_row_number` and `reason_code`; invalid values and field-specific details are not copied into the ledger. Malformed/missing schema fields use `MISSING_REQUIRED_FIELD`. A malformed source row number falls back to its 1-based position within the supplied batch so count reconciliation is maintained.
