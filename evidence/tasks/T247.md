# T247 — team-approved EDA route and bounded charts

Date: 2026-11-21. Prompt: [Stage F request](../../prompts/development/002-T243-stage-f-eda-ui.md). The user reported the [T243 team decision](T243.md), which permits the proposed fifth read-only page and its 3–5 contributor-day planning impact. The already-published [T246 aggregate](T246-full-source-eda-2026-11-21.md) was reused; no source scan or aggregation was repeated.

`frontend/src/main.ts` mounts `/eda` independently of the existing `/` case, model-risk and results workspace. `frontend/src/views.ts` adds a reciprocal navigation link and a semantic EDA page with source SHA-256, dataset version, synthetic origin, UTC coverage and upstream timezone/release caveat; source/accepted/rejected/warm-up/scoreable counts and quality counts; category and UTC-time transaction-count tables with visual bars; and paid/received amount tables separated by currency. Each series states its unit and transaction denominator. The 24 amount series are collapsed in native `<details>` disclosures for a manageable page; omitted-currency counts are explicit. Rendering uses `textContent` throughout, with no per-row/account/label display, cross-currency sum or invented values. The page includes accessible headings, labelled navigation, table equivalents, loading/empty/unavailable/error status and retry.

Synthetic UI RED: `npm run test -- --run tests/eda-ui.test.ts` failed **3 expected tests** while `createEdaView` and the `/eda` mount did not exist. After implementation, `npm run test -- --run tests/eda.test.ts tests/eda-ui.test.ts` passed **27/27**. Full T249 regression is recorded separately.
