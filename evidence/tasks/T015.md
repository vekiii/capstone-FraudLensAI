## Architecture and deterministic rule

Scorer is a structural typing.Protocol with score(Transaction) -> RiskAssessment.
FixtureScorer rotates constants (0.75, 0.40, 0.10) using (numeric TX suffix - 1) % 3,
for every contract-valid identifier. This is deliberately arbitrary fixture
variety, not an AML heuristic or predictive accuracy claim. scored_at copies
occurred_at. source=fixture, scorer_version=fixture-v1; explanation explicitly
states illustrative/synthetic provenance, no ML inference/verified fraud finding,
and the fixture timestamp convention. No clock, randomness, fallback or labels.
No risk-category field exists in the canonical schema; none was invented.

validate_transaction reconstructs strict inputs from stored model fields, so
mutated/model_construct/model_copy instances cannot skip T006 validation.
score_case in cases.py validates a case snapshot, invokes the injected scorer once
on a copy, rejects input mutation, revalidates every assessment field and enforces
transaction identity against the original validated input. Output snapshots are
independent of mutable caller/adapter objects. Extra fields, unknown sources,
nonfinite/type/range/metadata violations and missing fields are rejected.
ScoringError/CaseScoringError expose only generic messages with suppressed
chaining; no replacement score is returned. HTTP error mapping remains T016.

## Direct scoring/schema verification

Executed with the same UV variables; exit 0:

```powershell
@'
import json
import sys
from pathlib import Path

from jsonschema import Draft202012Validator, FormatChecker

sys.path.insert(0, str(Path.cwd() / 'backend/src'))
from fraudlens.cases import load_cases, score_case
from fraudlens.scoring import FixtureScorer

schema = json.loads(Path('specs/001-project-foundation/contracts/schemas.json').read_text())
validator = Draft202012Validator(
    {**schema, '$ref': '#/$defs/CaseDetail'}, format_checker=FormatChecker())
records = load_cases()
first = [score_case(case, FixtureScorer()).model_dump(mode='json') for case in records]
second = [score_case(case, FixtureScorer()).model_dump(mode='json') for case in records]
assert first == second
for detail in first:
    validator.validate(detail)
    assert detail['risk_assessment']['scored_at'] == detail['transaction']['occurred_at']
print(json.dumps([{
    'case_id': detail['case_id'],
    'transaction_id': detail['transaction']['transaction_id'],
    'score': detail['risk_assessment']['score'],
    'source': detail['risk_assessment']['source'],
    'scorer_version': detail['risk_assessment']['scorer_version'],
    'scored_at': detail['risk_assessment']['scored_at'],
} for detail in first]))
'@ | & ./.cache/bootstrap/bin/uv.exe run --locked python -
```
