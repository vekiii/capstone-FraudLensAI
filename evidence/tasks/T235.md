# T235 — read-only transaction risk endpoint

`GET /api/transactions/{transaction_id}/risk` in `backend/src/fraudlens/main.py`
requires the frozen canonical ID form, finds a verified label-free feature row,
checks eligibility and exact request/result identity, then returns the validated
closed `PredictionResult`. The status uses the unchanged threshold, `>=
0.2489517623052024`, with no daily suppression. It describes a synthetic AML
**risk score** requiring human review, identifies model and feature version, and
states only observed historical counts and payment category facts. No SHAP,
feature-contribution or causal claim is generated. No endpoint returns a target
label or performs a write. Synthetic API tests and the actual opt-in HTTP parity
probe are in [T231](T231.md) and [T233](T233.md).
