## Verification commands

```powershell
Get-FileHash data/raw/HI-Small_Trans.csv -Algorithm SHA256
Get-Item data/raw/HI-Small_Trans.csv | Select-Object Length,LastWriteTimeUtc
Get-Content data/raw/HI-Small_Trans.csv -TotalCount 1
```

The non-label scan used Python's CSV reader on `raw_line.rstrip(b'\r\n').rsplit(b',', 1)[0]`, removing the final label field before decoding/parsing. The PowerShell command piped the following script to `.\.venv\Scripts\python.exe -`:

```python
import csv
import re
from collections import Counter
from pathlib import Path

path = Path('data/raw/HI-Small_Trans.csv')
timestamp = re.compile(r'^\d{4}/\d{2}/\d{2} \d{2}:\d{2}$')
numeric = re.compile(r'^[+-]?\d+(?:\.\d+)?$')
counts = [Counter() for _ in range(10)]
rows = width_mismatches = 0
with path.open('rb') as source:
    source.readline()  # header only
    for raw_line in source:
        prefix = raw_line.rstrip(b'\r\n').rsplit(b',', 1)[0]
        fields = next(csv.reader([prefix.decode('utf-8')]))
        rows += 1
        if len(fields) != 10:
            width_mismatches += 1
            continue
        for index, value in enumerate(fields):
            if index == 0:
                kind = 'timestamp' if timestamp.fullmatch(value) else 'other_timestamp'
            elif not value:
                kind = 'empty'
            elif numeric.fullmatch(value):
                kind = 'numeric_lexical_text'
            else:
                kind = 'non_numeric_text'
            counts[index][kind] += 1
print(rows, width_mismatches, [dict(count) for count in counts])
```

The completed run took about 90 seconds on this workstation and printed only counts: 5,078,345 rows, zero non-label width mismatches; timestamp column all matching the pattern; banks and amount columns all numeric lexical text; account columns mixed numeric lexical and nonnumeric text; currencies and payment format all nonnumeric text. No label value was included in any output.
