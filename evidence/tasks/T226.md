## Implementation

[evaluation.py](../../backend/src/fraudlens/training/evaluation.py) validates nonempty binary labels and finite scores in `[0,1]`, then evaluates only passed-in score arrays. It maximizes positive-class F1 across distinct observed thresholds using exact integer count comparisons; ties choose higher precision and then higher threshold. It reports AP, ROC AUC with equal-score ties, Brier score, confusion counts, precision and recall, PR curve points, positive prevalence, P/R@20/50/100 with actual top-k denominators, and each observed UTC day's uncapped alert count including zero-alert days. Top-k score ties use transaction-ID Unicode order. The current-phase ranking accepts LightGBM summaries only and follows the T221 F1, AP, P@20, simplicity and declared-order rule. The separate T224 cross-family rule remains inactive.

This module takes explicit labels/scores; it does not read a partition or train a model. Test-label authorization and frozen prediction enforcement belong to later gated work. AP, ROC AUC and threshold metrics require both classes and reject single-class inputs rather than fabricating a value.
