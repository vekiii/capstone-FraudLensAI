## Implementation

`backend/src/fraudlens/cases.py` defines a strict, closed FixtureCase using the
existing Contract, CaseId and Transaction types. `load_cases(path=None)` uses the
repository-relative Settings.fixture_path by default, or an injected path.
It reads UTF-8 JSON, rejects duplicate JSON member names, validates all records,
rejects duplicate case/transaction IDs and returns fresh records sorted by case_id.
It does not rewrite files, cache mutable records, perform scoring or load on import.
The shipped collection has exactly three records; injected empty arrays are valid
for the established empty-state contract. No arbitrary three-record restriction
was added to the general loader.

FixtureLoadError('Unable to load synthetic cases.') with suppressed exception
chaining. Tests cover non-disclosure of raw paths, rejected values and messages.

path = Path('data/fixtures/cases.json')
schema = json.loads(Path('specs/001-project-foundation/contracts/schemas.json').read_text())
raw = json.loads(path.read_text(encoding='utf-8'))
storage_schema = {
    **schema, 'type': 'array', 'minItems': 3, 'maxItems': 3,
    'items': {
        'type': 'object', 'additionalProperties': False,
        'properties': {
            'case_id': schema['$defs']['CaseSummary']['properties']['case_id'],
            'transaction': {'$ref': '#/$defs/Transaction'},
        },
        'required': ['case_id', 'transaction'],
    },
}
Draft202012Validator(storage_schema, format_checker=FormatChecker()).validate(raw)
cases = load_cases()

    'cases': len(cases),
    'case_ids': [case.case_id for case in cases],
    'transactions': len(cases),
    'transaction_ids': [case.transaction.transaction_id for case in cases],
    'sha256': hashlib.sha256(path.read_bytes()).hexdigest(),

}))
