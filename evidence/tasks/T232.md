# T232 — versioned closed prediction contracts

The existing Feature 002 `data-risk-v1` JSON Schema in
`specs/002-data-and-risk-scoring/contracts/schemas.json` now binds the model
prediction to canonical ID shape, finite bounded score (Pydantic runtime gate),
model source, synthetic-data notice and closed required fields. Matching
`PredictionResult`, `RiskError` and `ModelHealth` Pydantic models are in
`backend/src/fraudlens/contracts.py`. The Foundation `Health` model still accepts
only `fixture`, and its original case/transaction schemas were not changed.
The model-mode health response is a separate variant. Contract tests validate
the JSON Schema and Pydantic models, including denial of target-label fields.
JSON itself has no NaN literal; Pydantic rejects nonfinite Python values.
