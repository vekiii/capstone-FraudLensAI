# T251 — hash-gated aggregate results API

Prompt: [T250/T251/T240 request](../../prompts/development/002-T250-T251-results-integration.md). Date: 2026-11-21. `backend/src/fraudlens/training/results.py` and `main.py` implement read-only `GET /api/model/results`. The route accepts no query parameters, requires explicit `APP_MODE=model`, and returns only bounded validation/test aggregates. The service verifies exact byte hashes **before JSON parsing**: T230 authorization evidence `0000543f…`, T230 completion evidence `d280179d…`, test report `5027dae9354796718a080086a6cadc0319d1b376336ad4dac8d93b4e534d9cdb`, frozen experiment `a9438363…`, lineage `9f1679c7…`, validation result `4d671b97…`, feature manifest `63873b79…`, native model `3b4e4019…` and trusted model manifest `c766e901…`. It checks report authorization flag, one-time test partition, sealed prediction SHA-256 `99727d426f78698ee9a0f37ec50c1c900dc848f13bed6ef0756544f76c3f04f7`, exact experiment/model/protocol/source/feature links, frozen threshold `0.2489517623052024`, validation metric lineage, aggregate counts and uncalibrated status. It does **not** open `accepted.jsonl`, label files or prediction CSV; it does not evaluate or train.

`ModelResults`/`PartitionResults`/`Metric` are closed Pydantic and JSON Schema contracts. Response partitions are validation (482,650 rows, 471 positive, 482,179 negative) and authorized test (233,070 rows, 218 positive, 232,852 negative), with UTC coverage, selected metrics/denominators, whole-partition P@K and uncapped daily alert counts. The 77,757-point test PR curve stays in the verified source report; the API supplies a bounded presentation subset. No individual labels or rows are returned. Missing/changed approval yields 409 `evaluation_not_authorized`; missing/tampered report yields 404 `results_unavailable`; any query yields 422 `invalid_request`. Controlled errors contain no local path or source content. The API is local single-user workflow authorization, not an account system.
