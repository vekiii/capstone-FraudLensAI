## Implementation and security decision

The existing `fraudlens.scoring` public API moved from `scoring.py` to `scoring/__init__.py` so `scoring/artifacts.py` can be imported without changing fixture callers. The new writer publishes a new local directory with `model.txt` and a canonical, versioned JSON `manifest.json`; it refuses overwrites and returns the manifest SHA-256 for independent retention. Metadata binds the model checksum/size, ordered raw and expanded matrix features, train-only categorical vocabularies, source and full protocol hashes, code revision, seed, validation metrics, threshold method/value, and exact Python/LightGBM versions.

`read_verified_artifact` requires a trusted expected manifest SHA-256 **from outside the artifact directory**, expected source/protocol hashes, and feature identity. It checks path containment, bounded file sizes, the manifest digest before JSON parsing, exact schema and locked versions, then model size/hash. Duplicate keys, nonfinite values, altered bytes and incompatible versions fail closed. It returns verified bytes and metadata; it never uses pickle/joblib or constructs a Booster. T233 must build the model adapter only from this authenticated output and additionally check native model matrix width/feature mapping. A manifest checksum stored only beside an untrusted model is insufficient authority.

The locked versions used here are CPython 3.14.10 and LightGBM 4.7.0, as established in [T222](T222.md). The complete approved FR-021 protocol digest does not exist yet, so this writer must not be used to imply a fit is authorized. The caller must retain the returned manifest digest in trusted configuration before later loading.
